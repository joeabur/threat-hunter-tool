# Example reports (simulated)

These three files were generated by running the tool over `sample-data/snapshots/lab-intrusion.json` and `sample-data/xdr/defender-xdr-export.json`. **All data is synthetic**: the host `WS-LAB-03`, its users, the addresses (from the RFC 5737 documentation ranges) and the "malware" names are invented. Only the file names were normalised; the contents are exactly as generated (the `GeneratedAt` value is the time of generation).

| File | Format |
|---|---|
| [lab-intrusion.json](lab-intrusion.json) | Full structured report |
| [lab-intrusion.csv](lab-intrusion.csv) | One row per finding |
| [lab-intrusion.html](lab-intrusion.html) | Human-readable report with a simulated-data banner |

Regenerate with `./scripts/Invoke-WindowsThreatHunter.ps1 -SnapshotPath ./sample-data/snapshots/lab-intrusion.json -DefenderXdrPath ./sample-data/xdr/defender-xdr-export.json -OutputDirectory ./reports/example`.
