# Code of Conduct

We want this project to be a respectful, harassment-free space for everyone who takes part, whatever their experience, background or identity.

## Expected behaviour

- Be kind and assume good faith.
- Give and accept constructive feedback about the work, not the person.
- Respect that people have different levels of security and PowerShell experience.

## Unacceptable behaviour

- Harassment, insults, discrimination, or personal attacks.
- Publishing someone else's private information, including real host names, account names or incident data from their environment.
- Using this project to plan or carry out unauthorized access to systems.

## Enforcement

Maintainers may edit, remove or reject contributions and may block participants who do not follow this code. Report concerns privately to the repository owner through the contact method on their GitHub profile, or through GitHub's private reporting if it is enabled for the repository.

This text is adapted in spirit from the Contributor Covenant, version 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
