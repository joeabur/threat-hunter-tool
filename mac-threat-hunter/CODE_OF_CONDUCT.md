# Code of Conduct

We follow the spirit of the Contributor Covenant 2.1: be respectful, welcoming and constructive;
no harassment, discrimination, personal attacks, or publishing others' private information.
Give and accept feedback graciously and focus on what is best for the community.

Maintainers may remove comments, commits or contributions that violate this code and may
temporarily or permanently ban contributors for behaviour they judge inappropriate.

Report concerns through a private GitHub security advisory or by contacting the maintainers
via the repository's contact options. Reports are handled confidentially.

Full text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
