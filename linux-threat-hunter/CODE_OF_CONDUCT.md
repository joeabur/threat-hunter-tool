# Code of Conduct

We want this project to be welcoming and professional for everyone, regardless of background or experience.

**Expected behavior:** be respectful and constructive; assume good faith; give and accept feedback graciously; focus on what is best for users and the community.

**Unacceptable behavior:** harassment, discrimination, personal attacks, trolling, publishing others' private information, or using the project to plan or promote unauthorized access to systems.

**Scope:** project spaces (issues, pull requests, discussions) and public representation of the project.

**Enforcement:** maintainers may remove comments, lock threads or ban participants who violate these standards. Report concerns privately to the maintainers using the contact in [SECURITY.md](SECURITY.md). Reports are handled confidentially.

This code is adapted in spirit from the Contributor Covenant (https://www.contributor-covenant.org).
